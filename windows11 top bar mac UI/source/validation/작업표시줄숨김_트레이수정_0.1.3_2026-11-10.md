# 작업 표시줄 숨김·트레이 열림 수정 — 0.1.3

검증일: 2026-11-10, 한국 시간. Windows 11 25H2(빌드 26200), 1920×1080 단일 모니터, 100% 배율 PC에서 확인했습니다.

## 바뀐 동작과 수정

### 작업 표시줄 완전 숨김

- 상단 바가 켜져 있는 동안 Windows 작업 표시줄(주 모니터 `Shell_TrayWnd`, 보조 모니터 `Shell_SecondaryTrayWnd`)을 완전히 숨깁니다. 앱 실행·전환은 독이 맡습니다.
- 작업 표시줄 자리를 화면으로 돌려받기 위해 숨기는 동안 Windows 자동 숨기기를 켜 둡니다. 숨기기 전에 원래 설정을 `%LOCALAPPDATA%\GlassDock\taskbar-state.json`에 기록합니다.
- 작업 표시줄이 다시 나타나거나 탐색기가 재시작되면(`TaskbarCreated`) 다시 숨깁니다. 숨긴 동안 사용자가 자동 숨기기 설정을 바꾸면 그 값을 종료 때 복원할 값으로 기록합니다.
- 복원 경로는 다음과 같습니다.
  - 정상 종료: 상단 바가 직접 되돌립니다.
  - 로그오프: `WM_QUERYENDSESSION`에서 되돌립니다.
  - 강제 종료: 별도 복구 감시 프로세스가 되돌립니다.
  - 그래도 남은 경우: 다음 실행이나 다음 로그온 때 되돌립니다.
- 복구 감시는 중간 실행 프로세스를 거쳐 시작하므로 상단 바의 프로세스 트리 밖에 있습니다. 허용되는 경우 작업 개체(job)에서도 분리합니다.
- 숨기는 동안에는 `HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce`에 `GlassDock.TopBar.RestoreTaskbar` 항목을 등록하고, 정상 복원되면 삭제합니다.
- 안내 문구의 "Windows 기본 작업 표시줄은 유지합니다."를 바뀐 동작에 맞게 수정했습니다.

### 트레이가 처음부터 최종 모습으로 열리지 않던 문제

사용자 화면 녹화를 프레임 단위로 확인했습니다. 화살표를 누른 직후 약 0.15초 동안 Windows 기본 트레이(밝은 회색 창)가 자체 위치와 펼침 애니메이션으로 보인 뒤에 유리 트레이로 바뀌었습니다.

- **원본 창 먼저 투명 처리:** Windows 트레이 창은 화면에 나타나기 전, 또는 처음 나타나는 순간 바로 투명하게 만들고, 유리 트레이가 그 상태를 이어받습니다.
- **배경 미리 준비:** 유리 배경(Composition)을 트레이 버튼 호출과 동시에 준비합니다.
- **덜 그려진 장면 차단:** 같은 장면이 연속 두 번 캡처돼야(애니메이션 종료) 표시합니다. 펼침 애니메이션 도중의 장면은 쓰지 않습니다.
- **동시 표시:** 배경과 아이콘을 0.12초 페이드로 함께 표시해, 어느 한쪽이 먼저 보이지 않게 합니다.

### 트레이 아이콘 툴팁이 화면에 남던 문제

트레이를 Esc나 코드로 닫거나, Windows의 툴팁 타이머가 늦게 실행되면 툴팁이 트레이 없이 화면 구석에 남았습니다. 닫을 때 트레이에 딸린 툴팁을 숨깁니다. 상단 바가 켜져 있는 동안에는 숨겨진 트레이에 나타나는 툴팁도 계속 숨깁니다.

| 실제 화면: 알림 | 작업 표시줄 숨김 상태에서 테스트 알림 배너가 상단 바 오른쪽 아래에 표시됨 |
| 정상 종료 | 작업 표시줄·자동 숨기기 설정 복원, 기록과 로그온 복원 항목 삭제 |
| 강제 종료 | 단일 프로세스 강제 종료, 프로세스 트리 강제 종료 모두 복구 감시가 작업 표시줄 복원 |

## 확인하지 못한 항목

- 보조 모니터 작업 표시줄: 단일 모니터 PC라 코드로만 처리했습니다.
- 탐색기 재시작 후 다시 숨기기: 열린 탐색기 창이 닫히므로 실제로 재시작하지 않았습니다.
- 로그오프·재부팅 복원: 실제로 수행하지 않았습니다. 로그온 복원 항목이 Windows에 등록·삭제되는 것까지만 확인했습니다.
- 수정 후 알림 배너 재검사: 화면 자동 조작 중 Windows가 "전체 화면 앱 실행 중" 상태로 모든 배너를 막아 재검사하지 못했습니다. 작업 표시줄 숨김 직후의 실제 화면 확인과 이전 자동 검사는 통과했습니다.
- 다른 PC·DPI 조합, 실제 카카오톡 알림 수신.

자동 조작으로 트레이를 열 때 두 번째 아이콘에 키보드 초점 테두리와 툴팁이 보이는 현상이 있었습니다. 수정 전 버전에서도 같았고, 실제 마우스로 연 화면에는 나타나지 않아 이번 수정 대상에 포함하지 않았습니다.

```powershell
dotnet run --project validation/TopBar/TopBarTests.csproj -c Release
dotnet run --project validation/Taskbar/TaskbarTests.csproj -c Release
dotnet run --project validation/Tray/TrayTests.csproj -c Release
dotnet run --project validation/AutoHide/AutoHideTests.csproj -c Release
```

실제 상단 바를 종료한 상태에서 실행하세요. 마우스 커서를 상단 바 위에 두면 최대화 자동 숨김 검사가 실패합니다(마우스가 올라가 있는 동안 상단 바를 유지하는 정상 동작).
