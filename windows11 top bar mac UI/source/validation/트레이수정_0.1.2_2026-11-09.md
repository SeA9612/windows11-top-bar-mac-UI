# 트레이 빈 화면 수정 — 0.1.2

검증일: 2026-11-09. 사용자 사진처럼 유리 창 안에 아이콘 대신 바탕화면이 보이는 오류를 재현하고 수정했습니다.

## 원인과 수정

- Explorer의 기존 팝업 HWND를 ShowWindow로 다시 보여주면 WinUI 내부의 펼침 상태·아이콘 시각 트리가 살아나지 않는 경우가 있었습니다. 매번 실제 트레이 버튼의 UI Automation 동작으로 펼칩니다.
- 현재 Windows의 버튼 클래스가 `SystemTray.AccentButton`, 이름이 `숨겨진 아이콘 표시 숨기기`로 조회돼 기존의 정확한 이름 비교가 실패했습니다. 해당 클래스 안에서 한국어·영어 숨겨진 아이콘 이름을 인식하도록 수정했습니다.
- 기본 작업 표시줄의 XAML 내용이 숨겨진 경우, 트레이 세션 동안 합성 트리를 유지합니다. 원래 작업 표시줄은 활성화하지 않고 거의 투명한 입력 표면으로 유지하며, 닫기·취소·비정상 종료 복구 시 원래 스타일과 자식 표시 상태를 복원합니다.
- 화면 복사 대체 경로를 제거했습니다. 트레이 자체 프레임을 읽지 못했을 때 뒤쪽 바탕화면을 아이콘 그림으로 잘못 사용하는 일이 없어집니다.
- 실제 아이콘 영역마다 비어 있지 않은 픽셀이 있는지 확인한 뒤 유리 표면을 생성합니다. 테두리나 배경의 대비만으로 성공을 판정하지 않습니다.
- 위치 이동 시 frame 변경을 함께 적용해 WinUI 입력 영역의 48픽셀 좌표 어긋남을 해결했습니다. 열기 전 위치도 보존해 닫을 때 되돌립니다.
- 비계층형 Composition 배경이 Explorer 입력 창 위에서 클릭을 가로막지 않도록, 배경은 네이티브 입력 창 아래에 배치했습니다. 아이콘 그림/테두리 창은 계층형 클릭 통과 표면으로 유지합니다.
- 초기화 도중 취소, 재열기, 자체 상단 바 활성화 시의 조기 닫힘도 보완했습니다.

상시 GPU 캡처 실험은 최종 코드에서 제거했습니다. 내부 펼침 상태를 바로잡은 뒤 정상적으로 읽히는 트레이 프레임을 사용하므로 캡처 테두리 권한이나 Windows 개인정보 설정을 변경하지 않습니다.

## 확인한 항목

- Release 빌드, 기본 상태·좌표·Win32 ABI 검사 42개.
- 실제 트레이 아이콘 7개 표시, 각 아이콘 영역의 실제 그림 픽셀 확인.
- 각 아이콘 중심점의 네이티브 마우스 대상이 Explorer인지 확인. 유리 배경이 입력을 가로막지 않음.
- 테스트 프로그램이 등록한 NotifyIcon의 아이콘 변경이 유리 그림에 반영됨.
- 그 테스트 아이콘의 실제 앱 콜백 도착 확인. 사용자 앱 아이콘을 실행하거나 외부 메시지를 보내지 않음.
- 바깥 클릭/포커스 이동으로 닫기, 원래 위치·스타일 복원, 다시 열기.
- 초기화 중 취소 후 작업 표시줄 스타일·자식 표시 상태 복원, 취소 후 재열기.
- 제품 EXE의 복구 감시 경로로 네이티브 스타일과 숨겨졌던 작업 표시줄 자식 상태 복원 확인.
- 최대화·복원 6회와 전체 화면·최소화 후 상단 바 좌표 유지 및 트레이 재열기.
- computer-use로 실제 상단 바 화살표를 눌러 아이콘이 보이는 화면과 닫기·재열기를 확인.

## 범위

현재 PC의 Windows 11 환경에서 확인했습니다. 실제 카카오톡 알림 수신, 다른 PC·모니터·DPI 전체 조합을 새로 검증한 것은 아닙니다. 0.1.1의 과거 미해결 기록과 인수인계 파일은 당시 상태를 보존하며, 이번 수정의 결과는 이 문서로 구분합니다.

```powershell
dotnet run --project validation/TopBar/TopBarTests.csproj -c Release
dotnet run --project validation/Tray/TrayTests.csproj -c Release
dotnet run --project validation/AutoHide/AutoHideTests.csproj -c Release
```

복구 감시 검사까지 포함하려면 빌드 후 `GLASSDOCK_TRAY_GUARD_TEST_APP`에 `artifacts/topbar-portable/GlassDock.TopBar.exe`의 절대 경로를 지정하고 트레이 검사를 실행합니다. 실제 상단 바를 종료한 상태에서 진행하세요.
