# 실행 ZIP 배포 검증 — v0.1.4

검증일: 2026-11-10, 한국 시간. Windows 11 x64 개발 PC에서 확인했습니다.

## 이번 업로드의 패키지 검사

- 0.1.4 소스에서 실행한 검사:
  - 상태·좌표·Win32 ABI·앱 분류 검사 72개 통과
  - 유리 시작 화면 검사 35개 통과
  - 작업 표시줄 숨김·복원 검사 16개 통과
  - 트레이 검사, 최대화 자동 숨김 검사 통과
- Release / win-x64 / self-contained로 게시했습니다. .NET SDK나 런타임을 설치하지 않고 실행하는 배포 방식입니다. 이전 빌드 파일이 섞이지 않도록 빈 폴더에 새로 게시했습니다.
- ZIP 무결성 검사를 통과했고, 압축을 푼 467개 파일의 SHA-256이 모두 일치했습니다. 체크섬 목록 파일은 따로 들어 있습니다. ZIP 안의 경로 구분자는 `/`입니다.
- coreclr.dll, hostfxr.dll, PresentationFramework.dll과 실행 EXE가 있는지 확인했습니다.
- Microsoft.NETCore.App 8.0.33, Microsoft.WindowsDesktop.App 8.0.33 런타임이 포함되어 있습니다.
- 압축을 푼 EXE의 ProductVersion이 0.1.4인지 확인했습니다. 창 없는 복구 감시 시작 경로는 종료 코드 0으로 끝났습니다. 두 번째 상단 바를 띄우는 검사는 아닙니다.
- 개인 설정·대화·로그·사용자 화면·빌드 캐시는 공개 소스와 ZIP에 넣지 않았습니다. 저장소의 화면 이미지(`assets/screenshots`)는 단색 그라데이션 배경 위에서 새로 찍었습니다.

## 같은 코드로 확인한 실제 UI 검사

배포 빌드(`Build-TopBar.ps1`)를 실제로 실행해 확인한 항목:
- Windows 키로 유리 시작 화면 열기·닫기
- "note"·"메모" 검색
- 범주 클릭과 Esc 단계
- 기본 시작 메뉴가 열리지 않는지

이 항목들은 버전 번호를 0.1.4로 올리기 직전, 코드가 같은 빌드에서 확인했습니다. 버전을 올린 뒤에는 자동 검사 5종을 다시 통과했습니다. 화면 이미지는 0.1.4로 올리기 직전 빌드에서 찍었습니다. 압축을 푼 실행본 자체로는 실제 UI 검사를 반복하지 않았습니다.

새로 검증하지 않은 항목:
- 관리자 권한 창이 맨 앞에 있을 때의 Windows 키 동작
- 보조 모니터와 다른 PC·DPI 조합
