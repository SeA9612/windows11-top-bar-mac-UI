# 실행 ZIP 배포 검증 — v0.1.3

검증일: 2026-11-10, 한국 시간. Windows 11 x64 개발 PC에서 확인했습니다.

## 이번 업로드의 패키지 검사

- 수정 소스에서 상태·좌표·Win32 ABI 검사 42개, 작업 표시줄 숨김·복원 검사 16개, 트레이 검사, 최대화 자동 숨김 검사 통과.
- Release / win-x64 / self-contained 게시. .NET SDK나 런타임 설치 없이 실행하는 배포 방식. 이전 빌드 파일이 섞이지 않도록 빈 폴더에 새로 게시.
- ZIP 무결성 검사 통과 및 압축 해제본의 467개 파일 SHA-256 일치. 체크섬 목록 파일 자체는 별도 포함. ZIP 안의 경로 구분자는 `/`.
- coreclr.dll, hostfxr.dll, hostpolicy.dll, PresentationFramework.dll과 실행 EXE 존재 확인.
- Microsoft.NETCore.App 8.0.33, Microsoft.WindowsDesktop.App 8.0.33 런타임 포함.
- 압축 해제 EXE ProductVersion 0.1.3 확인. 창 없는 복구 감시 시작 경로의 종료 코드 0 확인. 두 번째 상단 바를 띄우는 검사는 아님.
- 개인 설정·대화·로그·사용자 화면·인수인계 자료·빌드 캐시는 공개 소스와 ZIP에 포함하지 않음.

## 같은 소스로 확인한 실제 UI 검사

작업 표시줄이 사라지고 화면 아래 끝에 마우스를 대도 나타나지 않는 것을 확인했습니다. 최대화 창이 화면 아래 끝까지 차는 것도 확인했습니다. 작업 표시줄을 숨긴 상태에서 트레이를 열면 고속 화면 캡처 기준으로 처음부터 상단 바 아래 최종 위치·모습으로 나타났고, Windows 기본 트레이는 보이지 않았습니다. 정상 종료와 프로세스 트리 강제 종료 후 작업 표시줄·원래 자동 숨기기 설정이 돌아오는 것도 확인했습니다.

버전 번호(0.1.3)를 올리기 직전, 코드가 같은 실행본에서 확인한 결과입니다. 버전을 올린 뒤에는 자동 검사 4종을 다시 통과했습니다. 압축 해제본 자체로 실제 UI 검사를 반복하지는 않았습니다.
