# 실행 ZIP 배포 검증 — v0.1.5

검증일: 2026-11-18, 한국 시간. Windows 11 x64(25H2, 빌드 26200) 개발 PC에서 확인했습니다.

## 이번 업로드의 패키지 검사

- 0.1.5 소스에서 실행한 검사:
  - 상태·좌표·Win32 ABI·앱 분류 검사 72개 통과
  - 유리 시작 화면 검사 35개 통과(연속 3회). 이 검사는 수정 전 0.1.4 소스에서도 간헐 실패가 있어, 같은 조건에서 원본과 비교한 뒤 연속 통과를 확인했습니다.
  - 작업 표시줄 숨김·복원 검사 16개 통과, 트레이 검사와 최대화 자동 숨김 검사 통과(실제 상단 바를 끈 상태에서 실행)
- Release / win-x64 / self-contained로 빈 폴더에 새로 게시했습니다. .NET SDK나 런타임을 설치하지 않고 실행하는 배포 방식입니다.
- 압축을 푼 467개 파일의 SHA-256이 ZIP 안 체크섬 목록과 모두 일치했습니다. ZIP 안의 경로 구분자는 `/`입니다.
- coreclr.dll, hostfxr.dll, PresentationFramework.dll과 실행 EXE가 있는지 확인했습니다.
- Microsoft.NETCore.App 8.0.34, Microsoft.WindowsDesktop.App 8.0.34 런타임이 포함되어 있습니다.
- 압축을 푼 EXE의 ProductVersion이 0.1.5인지 확인했습니다. 0.1.4 때 확인한 창 없는 복구 감시 시작 경로는 이번에 다시 실행하지 않았습니다(해당 코드는 변경하지 않음).
- 개인 설정·대화·로그·사용자 화면·빌드 캐시는 공개 소스와 ZIP에 넣지 않았습니다.

- 크기: **76,607,008바이트**
- SHA-256: `4cd06751a41db2778e3d80d6e8f292877ee38475044cf1d50be82013478c236d`
- 저장소의 ZIP과 GitHub Release 첨부 파일은 같은 파일입니다.

## 같은 코드로 확인한 실제 동작

로컬 배포 폴더에 게시한 0.1.5 실행본을 실제로 실행해 확인한 항목:
- 데스크톱 전환(Ctrl+Win+→) 후에도 상단 바가 표시되고(`cloaked=0`), 돌아와도 정상
- 다음 데스크톱에서 Windows 키로 유리 시작 화면 열기 → Esc로 닫기
- 모든 데스크톱 고정 기록(`topbar.log`)

새로 검증하지 않은 항목:
- 고정 기능이 없는 다른 Windows 버전(예비 방식은 같은 코드로 독에서만 시험)
- 보조 모니터와 다른 PC·DPI 조합

[0.1.5 릴리즈 노트](../Release%20Notes/Release%20Note0.1.5%20ver.md)를 확인하세요.

## 실행 ZIP 배포 검증 — v0.1.4

검증일: 2026-11-10, 한국 시간. Windows 11 x64 개발 PC에서 확인했습니다.

### 이번 업로드의 패키지 검사

- 0.1.4 소스에서 실행한 검사:
  - 상태·좌표·Win32 ABI·앱 분류 검사 72개 통과
  - 유리 시작 화면 검사 35개 통과
  - 작업 표시줄 숨김·복원 검사 16개 통과
  - 트레이 검사, 최대화 자동 숨김 검사 통과
- Release / win-x64 / self-contained로 게시했습니다. .NET SDK나 런타임을 설치하지 않고 실행하는 배포 방식입니다. 이전 빌드 파일이 섞이지 않도록 빈 폴더에 새로 게시했습니다.
- ZIP 무결성 검사를 통과했고, 압축을 푼 467개 파일의 SHA-256이 모두 일치했습니다. 체크섬 목록 파일은 따로 들어 있습니다. ZIP 안의 경로 구분자는 `/`입니다.
- coreclr.dll, hostfxr.dll, PresentationFramework.dll과 실행 EXE가 있는지 확인했습니다.
- Microsoft.NETCore.App 8.0.33, Microsoft.WindowsDesktop.App 8.0.33 런타임이 포함되어 있습니다.
- 압축을 푼 EXE의 ProductVersion이 0.1.4인지 확인했습니다. 창 없는 복구 감시 시작 경로는 종료 코드 0으로 끝났습니다. 두 번째 상단 바를 띄우는 검사는 아닙니다.
- 개인 설정·대화·로그·사용자 화면·빌드 캐시는 공개 소스와 ZIP에 넣지 않았습니다. 저장소의 화면 이미지(`assets/screenshots`)는 단색 그라데이션 배경 위에서 새로 찍었습니다.

### ZIP

- 파일: `portable/GlassDock-TopBar-v0.1.4-win-x64.zip`
- 크기: **76,614,433바이트**
- SHA-256: `283093b57ad409a07311227a540e0e8870df8e9e64027b9d038869b7beb25011`
- 저장소의 ZIP과 GitHub Release 첨부 파일은 같은 파일입니다.

### 같은 코드로 확인한 실제 UI 검사

배포 빌드(`Build-TopBar.ps1`)를 실제로 실행해 확인한 항목:
- Windows 키로 유리 시작 화면 열기·닫기
- "note"·"메모" 검색
- 범주 클릭과 Esc 단계
- 기본 시작 메뉴가 열리지 않는지

이 항목들은 버전 번호를 0.1.4로 올리기 직전, 코드가 같은 빌드에서 확인했습니다. 버전을 올린 뒤에는 자동 검사 5종을 다시 통과했습니다. 화면 이미지는 0.1.4로 올리기 직전 빌드에서 찍었습니다. 압축을 푼 실행본 자체로는 실제 UI 검사를 반복하지 않았습니다.

새로 검증하지 않은 항목:
- 관리자 권한 창이 맨 앞에 있을 때의 Windows 키 동작
- 보조 모니터와 다른 PC·DPI 조합
