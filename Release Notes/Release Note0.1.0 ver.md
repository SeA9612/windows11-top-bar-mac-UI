# Release Note0.1.0 ver — GlassDock TopBar 개발 이력

개발·로컬 배포 정리: 2026-11-06. 문서 작성: 2026-11-09, 한국 시간. 당시 제품 버전은 0.1.0입니다. 현재 다운로드용 GitHub Release는 [0.1.1](Release%20Note0.1.1%20ver.md)입니다.

## 기본 기능

- 28 DIP 상단 바와 선택 모니터 위쪽 작업 영역 예약.
- 현재 전경 앱 이름, 앱·창 메뉴, 키보드 언어, 네트워크, 음량·음소거, 배터리, 날짜·시간과 달력.
- Windows 버튼에 PC 정보, 설정, Store, 최근 항목, 작업 관리자와 전원·잠금·로그아웃 메뉴.
- Explorer가 처리하는 실제 숨겨진 트레이 창의 위치 연동, 바깥 클릭·Esc·화살표 재클릭 닫기와 원래 위치·스타일 복원.
- 트레이 유리 스타일의 비정상 종료 복구 감시와 시작 시 복구.
- Windows 기본 알림 배너의 오른쪽 위 배치. 메시지 내용이나 발신자는 읽거나 저장하지 않음.
- 독과 같은 투명 유리 메뉴·하위 메뉴·패널·트레이, 배경 밝기에 따른 글자 색 조정. 분홍색 선택 효과 제거.

## 배경 변경 이력

불투명 배경을 완전히 투명하게 변경한 뒤, 가독성 요청으로 30% 불투명도를 시험했습니다. 이후 창 상태별 전환과 최대화 시 70% 불투명도를 거쳐, 이 개발 단계의 최종 규칙은 최대화·전체 화면에서 100% 불투명, 그 외 상태에서 경계선 없이 0%였습니다.

이 배경 규칙은 0.1.1의 **최대화 자동 숨김**으로 변경됐습니다. 옛 최대화 불투명 표시와 현재 자동 숨김을 혼동하지 마세요.

## 당시 검증과 배포

당시 기록에는 42개 상태·배치·Win32 ABI 검사, 밝고 어두운 배경의 메뉴·하위 메뉴, 실제 트레이 열기·닫기·클릭 영역·원래 위치와 스타일 복원, 테스트 Windows 알림 배치 확인이 있습니다. 카카오톡 실제 메시지 수신 검사는 하지 않았습니다.

실행본·소스 통합 ZIP은 당시 로컬에서 만들었습니다. 개인 설정, 로그와 카카오톡 대화 데이터를 포함하지 않았습니다. 위 결과는 당시 기록이며, 최신 환경에서 모든 기능이 통과했다는 의미는 아닙니다. 최신 재검사에서 발견된 트레이·알림 제한은 0.1.1 노트를 확인하세요.
