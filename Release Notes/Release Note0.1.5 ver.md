# Release Note0.1.5 ver — 모든 가상 데스크톱에 표시

배포일: **2026-11-18, 한국 시간**. 제품 버전: **0.1.5**. Git 태그: `v0.1.5`.

[런타임 포함 실행 ZIP 다운로드](https://github.com/SeA9612/windows11-top-bar-mac-UI/releases/download/v0.1.5/GlassDock-TopBar-v0.1.5-win-x64.zip)

ZIP의 전체 압축을 풀고 `GlassDock.TopBar.exe`를 실행합니다. Windows 11 x64용이며 .NET·SDK 설치나 소스 빌드가 필요하지 않습니다. 기존 상단 바가 켜져 있으면 종료한 뒤 새 실행본을 사용하세요.

## 수정: 데스크톱을 전환하면 상단 바가 사라지던 문제

- **증상:** Windows 데스크톱을 전환하면(Ctrl+Win+←/→, 작업 보기에서 다른 데스크톱 선택) 상단 바가 보이지 않았습니다. 상단 바가 Windows 작업 표시줄을 숨기고 있어서, 다른 데스크톱에서는 상단 바도 작업 표시줄도 없는 화면이 됐습니다.
- **원인:** Windows가 상단 바 창을 처음 실행한 데스크톱에 속한 일반 앱 창으로 보고, 다른 데스크톱에서는 숨겼습니다(DWM `cloaked` 값 2).
- **수정 1 — 모든 데스크톱에 고정:** 작업 보기에서 창을 우클릭해 고르는 "모든 데스크톱에 이 창 표시"와 같은 방식으로 상단 바 창을 고정합니다. 전환 애니메이션 중에도 사라지지 않습니다. 공식 문서가 없는 Windows 셸 기능이라, 2초마다 고정 상태를 확인해 새로 연 창(유리 시작 화면 등)과 탐색기 재시작 후 풀린 고정을 다시 적용합니다.
- **수정 2 — 예비 방식:** 고정 기능을 쓸 수 없는 Windows 버전에서는, 전환으로 상단 바 창이 숨겨지는 순간 공식 API(`IVirtualDesktopManager.MoveWindowToDesktop`)로 현재 데스크톱에 옮깁니다. 이 경우 전환할 때 잠깐 깜빡일 수 있습니다.
- 동작 기록은 `%LOCALAPPDATA%\GlassDock\topbar.log`에 짧게 남습니다. 추가 파일: [AllDesktops.cs](../windows11%20top%20bar%20mac%20UI/source/src/TopBar/AllDesktops.cs).
- 같은 문제를 겪던 [GlassDock 독](https://github.com/SeA9612/windows11-glass-dock-mac-UI)도 0.3.1로 함께 수정했습니다.

0.1.4의 유리 시작 화면, 0.1.3의 작업 표시줄 완전 숨김과 트레이 수정은 그대로 유지합니다.

## 검증 결과

| 항목 | 결과 |
|---|---|
| 원인 확인 | 수정 전, 다음 데스크톱에서 상단 바 창 `cloaked=2` |
| 데스크톱 전환 | 다음 데스크톱에서도 상단 바 `cloaked=0`, 돌아와도 정상. 게시한 0.1.5 실행본으로 다시 확인 |
| 데스크톱 2에서 유리 시작 화면 | Windows 키로 열기(창과 유리 배경 모두 표시) → Esc로 닫기 정상 |
| 예비 방식 | 고정을 끈 시험 모드에서 독으로 같은 코드를 확인(전환 후 현재 데스크톱으로 이동해 표시) |
| 기본 검사 | 72개 통과 |
| 유리 시작 화면 검사 | 35개 통과(연속 3회). 수정 전후 모두 간헐 실패가 있어 원본 0.1.4 소스와 비교 확인 |
| 작업 표시줄·트레이·최대화 자동 숨김 | 통과(실제 상단 바를 끈 상태에서 실행) |

유리 시작 화면 검사는 실제 화면 픽셀과 앱 목록을 사용해 실행 중 간헐적으로 실패했습니다(기본 시작 메뉴 감지 표본, 검색 순위 확인). 수정하지 않은 0.1.4 소스에서도 같은 조건에서 실패와 통과가 섞여 나와 이번 수정과 무관한 것으로 판단했고, 수정본은 이어서 3회 연속 통과했습니다.

## 배포와 남은 범위

이번 배포도 **미리보기 배포본**입니다. 다음은 확인하지 못했습니다.

- 다른 Windows 버전에서 고정 기능이 없는 경우의 상단 바 동작(예비 방식은 독으로만 시험)
- 보조 모니터와 여러 데스크톱의 조합
- 0.1.4에서 남은 항목: 관리자 권한 창이 맨 앞에 있을 때 Windows 키 동작, 다른 화면 배율·다른 PC, 탐색기 재시작 후 작업 표시줄 다시 숨기기, 실제 로그오프·재부팅 후 복원, 알림 배너 재검사

0.1.4 릴리즈와 태그는 당시 기록으로 유지합니다. 개인 설정·로그·대화·사용자 화면은 공개 업로드에 포함하지 않았습니다.
