# Release Notes

Windows 11 TopBar의 기능, 수정 사항과 확인된 제한을 버전별로 기록합니다. 날짜는 한국 시간 기준입니다. 독은 [별도 저장소](https://github.com/SeA9612/windows11-glass-dock-mac-UI)에서 배포합니다.

| 버전 | 날짜 | 내용 |
|---|---|---|
| [0.1.1 · 미리보기 배포](Release%20Note0.1.1%20ver.md) | 2026-11-09 | 최대화 자동 숨김, 작업 영역 복원, 28픽셀 위치 밀림 수정, 투명 버튼 클릭 영역 보완, 첫 전용 GitHub 실행본 |
| [0.1.0 · 개발 이력](Release%20Note0.1.0%20ver.md) | 개발 정리 2026-11-06 | 투명 상단 바, 시스템 메뉴, 네이티브 트레이·알림 위치 연동, 유리 팝업, 로컬 배포 |

0.1.0은 과거 로컬 개발 기록입니다. 이번에 과거 날짜의 GitHub Release를 만들거나 당시 파일을 현재 실행본으로 배포하지 않습니다. 현재 실행본의 소스·제품 버전은 **0.1.1**이며, 미해결 트레이 표시 오류가 있어 미리보기 배포로 표시했습니다.
