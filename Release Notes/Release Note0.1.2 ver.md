## 오류 수정

### 트레이 창 안에 아이콘 대신 바탕화면이 보이는 문제

기존 Explorer 팝업 HWND를 단순히 다시 표시하면 Windows 내부의 펼침 상태와 아이콘 시각 트리가 활성화되지 않을 수 있었습니다. 실제 숨겨진 아이콘 버튼의 UI Automation 동작으로 매번 펼치도록 수정했습니다.

현재 Windows에서 사용하는 `SystemTray.AccentButton` 클래스와 `숨겨진 아이콘 표시 숨기기`라는 이름을 인식하도록 호환 처리를 추가했습니다. 숨겨진 작업 표시줄의 XAML 내용도 트레이 세션 동안 유지하고, 닫기·취소·비정상 종료 시 원래 스타일과 자식 표시 상태를 복원합니다.

트레이 그림을 읽지 못할 때 뒤쪽 화면을 복사하던 대체 경로를 제거했습니다. 이제 각 아이콘 영역에 실제 그림 픽셀이 있는지 확인한 뒤 유리 표면을 만듭니다. 빈 창의 테두리나 배경 대비만으로 정상이라고 판정하지 않습니다.

### 아이콘이 보여도 클릭이 전달되지 않는 문제

유리 합성 배경이 Explorer 입력 창 위에서 마우스를 가로막지 않도록 창 순서를 수정했습니다. 유리 배경은 실제 입력 창 아래에, 아이콘과 테두리 표면은 클릭 통과 상태로 배치합니다.

위치 변경 시 프레임도 갱신해 WinUI 클릭 영역이 48픽셀 어긋나는 경우를 수정했습니다. 열기 전 위치를 저장하고 닫을 때 복원합니다.

### 초기화·닫기·복구

- 열기 도중 취소한 세션이 뒤늦게 팝업을 남기지 않도록 세션 식별 처리를 추가했습니다.
- 취소한 뒤 다시 열어도 아이콘이 표시되도록 정리 경로를 보완했습니다.
- 상단 바나 표시 표면이 활성화됐을 때 트레이가 조기에 닫히는 경우를 보완했습니다.
- 복구 감시가 숨겨진 작업 표시줄 자식 상태까지 복원하도록 확장했습니다.
- 이전 최대화·복원 위치 수정과 자동 숨김 동작을 유지했습니다.

상시 GPU 캡처 실험은 최종 배포에 포함하지 않았습니다. 별도의 캡처 테두리 권한 요청이나 Windows 개인정보 설정 변경 없이 동작합니다.

## 배포와 남은 범위

이번 배포는 **0.1.2 미리보기 배포본**입니다. 0.1.1에서 확인된 트레이 빈 화면 오류는 현재 PC에서 수정·검증했습니다. 다만 실제 카카오톡 알림 수신, Windows 배너 수신·배치, 다른 PC·보조 모니터·DPI 전체 조합은 이번에 새로 검증하지 않았습니다. 기존 알림 검증 제한을 수정 완료로 표시하지 않습니다.

소스·실행 ZIP·체크섬·안내 문서를 함께 업데이트했습니다. 0.1.1 릴리즈와 태그는 당시 기록으로 유지합니다. 개인 대화·설정·로그·사용자 화면과 인수인계 자료는 공개 업로드에 포함하지 않습니다.
